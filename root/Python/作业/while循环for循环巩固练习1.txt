练习题
基础打印（for 循环）
用for循环打印出 1~5 的每个数字，每个数字占一行。

基础打印（while 循环）
用while循环打印出 1~5 的每个数字，每个数字占一行。

累加求和（for 循环）
用for循环计算 1~10 的总和，并打印结果。

累乘求积（while 循环）用while循环计算 1~10 的乘积（1×2×3×…×10），并打印结果。

筛选打印（for 循环）用for循环遍历 1~10，只打印其中的偶数（2、4、6、8、10）。

筛选打印（while 循环）用while循环遍历 1~20，只打印其中的奇数（1、3、5、…、19）。

用户输入求和（for 循环）让用户输入一个正整数n，用for循环计算 1~n的总和，并打印结果。

倒序计数（while 循环）让用户输入一个正整数m，用while循环从m倒着数到 1（例如输入 3，输出 3、2、1）。

图形打印（for 循环）用for循环打印一个由*组成的直角三角形，共 5 行（第 1 行 1 个*，第 2 行 2 个*，直到第 5 行 5 个*）。

正方形打印（while 循环）让用户输入一个正整数s（代表边长），用while循环打印一个由#组成的正方形（例如输入 3，打印 3 行，每行 3 个#）。





















答案
基础打印（for 循环）

# 用for循环遍历1~5的范围并打印
for num in range(1, 6):
    print(num)

基础打印（while 循环）

# 初始化变量为1
num = 1
# 当num小于等于5时循环
while num <= 5:
    print(num)
    # 变量自增1
    num += 1

累加求和（for 循环）

total = 0  # 初始化总和为0
# 遍历1~10
for num in range(1, 11):
    total += num  # 累加每个数字
print("1~10的总和是：", total)

累乘求积（while 循环）

product = 1  # 初始化乘积为1（乘法初始值为1）
num = 1      # 从1开始
# 当num小于等于10时循环
while num <= 10:
    product *= num  # 累乘每个数字
    num += 1        # 变量自增1
print("1~10的乘积是：", product)

筛选打印（for 循环）

# 遍历1~10
for num in range(1, 11):
    # 判断是否为偶数（能被2整除）
    if num % 2 == 0:
        print(num)

筛选打印（while 循环）

num = 1  # 从1开始
# 当num小于等于20时循环
while num <= 20:
    # 判断是否为奇数（不能被2整除）
    if num % 2 != 0:
        print(num)
    num += 1  # 变量自增1

用户输入求和（for 循环）

# 获取用户输入的正整数n
n = int(input("请输入一个正整数："))
total = 0  # 初始化总和为0
# 遍历1~n
for num in range(1, n + 1):
    total += num  # 累加每个数字
print(f"1~{n}的总和是：", total)

倒序计数（while 循环）

# 获取用户输入的正整数m
m = int(input("请输入一个正整数："))
# 当m大于等于1时循环
while m >= 1:
    print(m)
    m -= 1  # 变量自减1

图形打印（for 循环）

# 外层循环控制行数（1~5行）
for row in range(1, 6):
    # 内层循环控制每行的*数量（与行数相同）
    for star in range(row):
        print("*", end="")  # 不换行打印*
    print()  # 每行结束后换行

正方形打印（while 循环）

# 获取用户输入的边长s
s = int(input("请输入正方形的边长："))

# 外层循环控制行数（共s行）
row = 1
while row <= s:
    # 内层循环控制每行的#数量（共s个）
    col = 1
    while col <= s:
        print("#", end="")  # 不换行打印#
        col += 1
    print()  # 每行结束后换行
    row += 1
