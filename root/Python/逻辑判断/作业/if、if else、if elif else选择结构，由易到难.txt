一、if 单分支结构（5 道）
1.简单条件判断
定义变量score = 95，使用if语句判断如果score >= 90，则打印 “成绩优秀”。

2.用户输入判断
让用户输入一个整数，使用if语句判断如果该数是偶数（num % 2 == 0），则打印 “这是一个偶数”。

3.字符串包含判断
定义变量fruit = "apple"，使用if语句判断如果字符串中包含 “app”（"app" in fruit），则打印 “包含 'app' 子串”。

4.比较运算判断定义变量a = 10，b = 20，使用if语句判断如果a + 15 > b，则打印 “a 加 15 大于 b”。

5.逻辑运算判断
让用户输入年龄和身高（厘米），使用if语句判断如果年龄 >=18 且身高 >=170，则打印 “符合参军基本条件”。

二、if else 双分支结构（5 道）
1.基础二选一判断
定义变量num = 7，使用if else判断：如果num是正数，打印 “正数”；否则打印 “非正数”。

2.用户输入二选一
让用户输入一个整数，使用if else判断：如果该数能被 3 整除，打印 “能被 3 整除”；否则打印 “不能被 3 整除”。

3.字符串判断二选一
定义变量password = "123456"，使用if else判断：如果密码长度 >=6，打印 “密码符合要求”；否则打印 “密码太短”。用内置函数len()判断字符串长度

4.比较运算二选一
定义变量x = 5，y = 8，使用if else判断：如果x * 2 > y，打印 “x 的 2 倍大于 y”；否则打印 “x 的 2 倍不大于 y”。

5.逻辑运算二选一
让用户输入两个整数a和b，使用if else判断：如果a和b都是偶数，打印 “两个都是偶数”；否则打印 “至少一个不是偶数”。

三、if elif else 多分支结构（5 道）

1.成绩等级判断
定义变量score = 75，使用if elif else判断等级：90-100→“A”，80-89→“B”，60-79→“C”，0-59→“D”，并打印等级。

2.年龄段判断
让用户输入年龄，使用if elif else判断：0-12→“儿童”，13-17→“青少年”，18-64→“成年人”，65 及以上→“老年人”，并打印结果。

3.数字范围判断
定义变量num = -5，使用if elif else判断：num > 0→“正数”，num == 0→“零”，num < 0→“负数”，并打印结果。

4.菜单选择判断
打印菜单 “1. 早餐 2. 午餐 3. 晚餐”，让用户输入数字 1-3，使用if elif else打印对应餐食，输入其他数字打印 “无效选择”。

5.综合条件判断让用户输入考试分数（0-100）和出勤次数（整数），使用if elif else判断：
分数 >=60 且出勤 >=20→“考试通过”
分数 >=60 但出勤 <20→“出勤不足，未通过”
分数 <60 但出勤>=20→“分数不够，未通过”
其他→“双重不达标，未通过”






















答案
一、if 单分支结构
简单条件判断

score = 95
if score >= 90:
    print("成绩优秀")  # 输出：成绩优秀

用户输入判断

num = int(input("请输入一个整数："))
if num % 2 == 0:
    print("这是一个偶数")  # 输入偶数时触发

字符串包含判断

fruit = "apple"
if "app" in fruit:
    print("包含'app'子串")  # 输出：包含'app'子串

比较运算判断

a = 10
b = 20
if a + 15 > b:  # 10+15=25>20
    print("a加15大于b")  # 输出：a加15大于b

逻辑运算判断

age = int(input("请输入年龄："))
height = float(input("请输入身高（厘米）："))
if age >= 18 and height >= 170:
    print("符合参军基本条件")  # 年龄和身高都达标时触发

二、if else 双分支结构
基础二选一判断

num = 7
if num > 0:
    print("正数")  # 7是正数，输出：正数
else:
    print("非正数")

用户输入二选一

num = int(input("请输入一个整数："))
if num % 3 == 0:
    print("能被3整除")
else:
    print("不能被3整除")  # 输入不能被3整除的数时触发

字符串判断二选一

password = "123456"
if len(password) >= 6:  # 长度为6，满足条件
    print("密码符合要求")  # 输出：密码符合要求
else:
    print("密码太短")

比较运算二选一

x = 5
y = 8
if x * 2 > y:  # 5*2=10>8
    print("x的2倍大于y")  # 输出：x的2倍大于y
else:
    print("x的2倍不大于y")

逻辑运算二选一

a = int(input("请输入整数a："))
b = int(input("请输入整数b："))
if a % 2 == 0 and b % 2 == 0:
    print("两个都是偶数")
else:
    print("至少一个不是偶数")  # 有一个奇数时触发

三、if elif else 多分支结构
成绩等级判断

score = 75
if 90 <= score <= 100:
    print("A")
elif 80 <= score <= 89:
    print("B")
elif 60 <= score <= 79:  # 75符合该条件
    print("C")  # 输出：C
else:
    print("D")

年龄段判断

age = int(input("请输入年龄："))
if 0 <= age <= 12:
    print("儿童")
elif 13 <= age <= 17:
    print("青少年")
elif 18 <= age <= 64:
    print("成年人")  # 输入20时触发
else:
    print("老年人")

数字范围判断

num = -5
if num > 0:
    print("正数")
elif num == 0:
    print("零")
else:  # -5<0
    print("负数")  # 输出：负数

菜单选择判断

print("1. 早餐 2. 午餐 3. 晚餐")
choice = int(input("请输入选择（1-3）："))
if choice == 1:
    print("早餐")
elif choice == 2:
    print("午餐")  # 输入2时触发
elif choice == 3:
    print("晚餐")
else:
    print("无效选择")

综合条件判断

score = int(input("请输入考试分数（0-100）："))
attendance = int(input("请输入出勤次数："))
if score >= 60 and attendance >= 20:
    print("考试通过")
elif score >= 60 and attendance < 20:
    print("出勤不足，未通过")
elif score < 60 and attendance >= 20:
    print("分数不够，未通过")
else:
    print("双重不达标，未通过")  # 分数<60且出勤<20时触发
